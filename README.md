# 📝 To-Do List App

A responsive and visually appealing **To-Do List Web App** built using **HTML, CSS, and JavaScript**.  
It allows users to add, edit, delete, and mark tasks as done — all saved locally using `localStorage`.

---

## 🌟 Features

- ➕ **Add Tasks** – Instantly create and view new tasks.
- ✅ **Mark as Done** – Highlight completed tasks.
- 🗑️ **Delete Tasks** – Remove unwanted tasks easily.
- ✏️ **Edit Tasks** – Update your notes anytime.
- 💾 **Persistent Storage** – Uses `localStorage` to save tasks even after reload.
- 📱 **Fully Responsive Design** – Works seamlessly on mobile, tablet, and desktop.
- 🎨 **Modern UI** – Styled with a soft glassmorphism and gradient background.
